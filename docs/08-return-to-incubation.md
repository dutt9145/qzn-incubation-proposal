# 08 — Return to Incubation

## Mechanism: Hybrid

Two components, both sourced from protocol activity (not from ICO proceeds).

## Component A — Revenue share

| | |
|---|---|
| What | 7.5% of every accumulator flush, paid quarterly |
| Sourced from | Reserve stream (5%) + half of operations stream (2.5%) |
| Effective rate | ~1.5% of standard match value, ~1.125% of tournament value |
| Starts | M1 completion (audit done, mainnet live) |
| Stops | Cap reached OR 36 months elapsed |
| **Cap** | **10,000,000,000 QU (40% of grant)** |
| Mechanism | Quarterly multi-sig transfer from QZN_TreasuryVault |

**Why a 10B cap, not larger.** Component A is supplementary revenue share, not principal recovery. The Board is structurally exposed to QZN's success through Component B (the token allocation, the primary return vehicle). Component A adds tier-2 return tied to actual protocol adoption. At realistic adoption levels the 36-month sunset binds before the cap; the cap sized at 10B provides meaningful payout at strong adoption without creating excessive ongoing obligation. Combined with Component B at Phase 3 ICO price, this structure breaks even at 1× principal at 1,000 QU/QZN token price.

## Component B — Token allocation

| | |
|---|---|
| Amount | 15,000,000 QZN (6.0% of 250M total supply) |
| Sourced from | Dedicated Incubation Program allocation, reserved before any other distribution |
| Delivered | On ICO close |
| Vesting | 36-month linear vest, no cliff |
| Launch value | At ICO Phase 2 (800 QU/QZN): 12B QU |
| Break-even price | 1,000 QU/QZN (Phase 3 ICO price) returns full 15B QU |
| Rights conveyed | Token utility only — no LLC equity, no board seats |

## Component C — Ecosystem contributions (not "return" but worth naming)

- Permanent QU burn of 10–13% per standard match
- QSWAP liquidity seed at launch: 2.5B QU + 10M QZN from ICO proceeds
- Post-cap perpetual contribution of 0.25% of accumulator to Qubic ecosystem fund

## Quarterly reports

Post-M1 completion, every quarter QZN publishes:

- Match settlement count + gross routed value
- Accumulator flush totals + per-stream breakdown
- Component A paid + cumulative + cap remaining
- Burn per epoch + cumulative
- QSWAP TVL contribution
- Post-ICO: Component B vest tranche delivered

Reports are publicly posted to the proposal repository and shared directly with the Incubation Board's assigned project manager.

## Three scenarios

| | Bear | Base | Bull |
|---|---|---|---|
| Component A Year 1 | ~5K QU | ~50K QU | ~500K QU |
| Component B at launch (Phase 2 price) | 12B QU | 12B QU | 12B QU |
| Component B at Phase 3 price (1,000 QU/QZN) | 15B QU | 15B QU | 15B QU |
| Component B at 3x token appreciation | 36B QU | 36B QU | 36B QU |
| Component B at 5x token appreciation | 60B QU | 60B QU | 60B QU |
| Cumulative burn (Year 3) | Modest | Tens of millions | Hundreds of millions |
| Component A cap hit during sunset | No | No | Possibly |

**Component B is the primary return mechanism.** At ICO Phase 2 launch, the Board's 15M QZN allocation represents 12B QU of value (48% of grant principal). At Phase 3 token price (1,000 QU/QZN), Component B alone returns the full 15B QU — combined with Component A potential of up to 10B QU, the Board reaches 1× principal recovery without requiring further token appreciation. Above Phase 3 price, the Board exceeds 1× return.

**Vesting note.** Component B vests linearly over 36 months with no cliff. Realized value depends on QZN performance through the vesting period — launch value is a point-in-time reference, not a guaranteed return.

## Summary of return triggers and conditions

| Trigger | Effect |
|---|---|
| M1 completion (audit done, mainnet live) | Component A quarterly payments begin |
| ICO close | Component B vesting begins (1/36 per month, no cliff) |
| 36 months after M1 completion | Component A sunset — payments stop regardless of cap |
| Component A cumulative payments hit 10B QU | Component A cap reached — payments stop regardless of time remaining |
| 36 months after ICO close | Component B fully vested |
| Each quarter post-M1 | Quarterly Incubation report published |
